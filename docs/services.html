Assessment & strategy

A two-week, fixed-scope audit of your clusters, pipelines and operating practices. It is the lowest-risk way to work with us: you get a scored report and a roadmap whether or not we do anything further together.

What’s included

  • Cluster health audit: versions, node pools, add-ons, resource requests and limits
  • Security review against the CIS Kubernetes Benchmark
  • CI/CD and release process walkthrough
  • Observability, backup and DR review
  • Cost and utilisation analysis
  • Readiness review for teams not yet on Kubernetes

Deliverables

  • Scored maturity report across ten areas
  • Prioritised findings: critical, high, medium, low
  • Target architecture recommendation
  • 90-day roadmap with effort estimates
  • Read-out session with your engineers and leadership

Typical duration: 2 weeks

Want a quick self-check first? The free online readiness assessment takes about three minutes.

Cluster design & build

Production-ready clusters and landing zones, provisioned entirely from code in your own accounts or data centre.

What’s included

  • Architecture design: topology, networking, identity, storage
  • Landing zones: accounts or projects, VPCs, IAM, guardrails
  • Infrastructure as code with Terraform, OpenTofu or Crossplane
  • Node configuration with Ansible or immutable OS images
  • Core add-ons: CNI, ingress or Gateway API, cert-manager, External Secrets, DNS
  • Environment strategy for dev, staging and production

Deliverables

  • Architecture decision records
  • IaC modules and pipelines in your repositories
  • Running clusters that pass agreed acceptance tests
  • Operations runbooks

Typical duration: 3–8 weeks

See the reference architectures for managed cloud, on-premises, bare metal and edge.

Migration & upgrades

Moving workloads onto Kubernetes, between clouds, or across Kubernetes versions — in planned waves with a rollback path for each.

What’s included

  • VMs and legacy applications to containers
  • Docker Compose and Swarm to Kubernetes
  • Cloud-to-cloud and on-prem-to-cloud cluster moves
  • Version upgrades, including deprecated API remediation
  • Stateful workload and data migration planning
  • Cut-over rehearsals and rollback plans

Deliverables

  • Application inventory and migration wave plan
  • Dockerfiles, Helm charts or Kustomize overlays
  • Upgrade runbook and test results
  • Post-migration review

Typical duration: 2–12 weeks, by portfolio size

GitOps & CI/CD

Every change to clusters and applications flows through Git, is reviewed, and can be rolled back in one step.

What’s included

  • Argo CD or Flux setup with multi-cluster structure
  • Repository layout and promotion between environments
  • CI pipelines: build, test, scan, sign, publish
  • Progressive delivery: canary and blue-green rollouts
  • Secrets handling with External Secrets or Sealed Secrets

Deliverables

  • GitOps repositories and bootstrap scripts
  • Pipeline templates teams can reuse
  • Release and rollback runbooks

Typical duration: 2–6 weeks

Platform engineering

An internal developer platform that lets product teams ship without filing tickets — built from the tools you already run.

What’s included

  • Developer journey mapping and platform roadmap
  • Golden-path templates for new services
  • Self-service namespaces, environments and databases
  • Backstage portal with software catalogue and TechDocs, when it fits
  • Platform APIs with Crossplane compositions

Deliverables

  • Working platform MVP with two or more golden paths
  • Platform team operating model
  • Adoption metrics and feedback loop

Typical duration: 6–12 weeks

Security & compliance

Hardened clusters, enforced policy and a secure software supply chain — mapped to the frameworks your auditors ask about.

What’s included

  • CIS Kubernetes Benchmark hardening and reporting
  • Least-privilege RBAC and SSO integration
  • Pod Security Standards enforcement
  • Default-deny network policies with Cilium or Calico
  • Policy-as-code with Kyverno or OPA Gatekeeper
  • Supply chain: image scanning, SBOMs, signing and verification
  • Runtime threat detection with Falco

Deliverables

  • Hardening report with before/after results
  • Policy library in Git
  • Control mapping matrix and evidence guide

Typical duration: 3–8 weeks

Compliance mapping

We map Kubernetes controls to the framework requirements you must meet and show where evidence comes from. We support your audit; certification itself is issued by your auditor.

How Kubernetes controls support common frameworks
FrameworkKubernetes controls we map
SOC 2Access control (RBAC, SSO), change management through GitOps, audit logging, monitoring and incident response
ISO 27001Annex A controls for access, cryptography, operations security, logging and supplier relationships
PCI DSSNetwork segmentation with network policies, workload isolation, vulnerability management and log retention
HIPAAEncryption in transit and at rest, access logging, backup and contingency planning for ePHI workloads
GDPRData residency through region and cluster placement, access restriction and deletion procedures
India DPDP ActData localisation options, access controls, breach detection and logging to support reporting obligations

Observability

Know what is broken, and why, before your users tell you.

What’s included

  • Metrics with Prometheus and long-term storage
  • Logs with Loki and traces via OpenTelemetry
  • Grafana dashboards for clusters, platform and applications
  • SLO definitions and burn-rate alerting
  • Alert routing and on-call integration

Deliverables

  • Observability stack deployed as code
  • Dashboards and alert rules in Git
  • Alert runbooks for every paging alert

Typical duration: 2–5 weeks

Reliability, backup & DR

Recovery targets agreed up front and proven by drills, not assumed.

What’s included

  • RTO and RPO definition per application tier
  • Backup and restore with Velero and storage snapshots
  • High-availability control planes and multi-zone workloads
  • Pod disruption budgets and graceful failover
  • Chaos testing in non-production environments

Deliverables

  • DR plan with documented RTO/RPO
  • Restore test report
  • Chaos experiment results and fixes

Typical duration: 2–6 weeks

FinOps & cost optimisation

Spend only on what your workloads actually use, and show each team what it costs.

What’s included

  • Requests and limits rightsizing
  • Cluster and node autoscaling with Karpenter or Cluster Autoscaler
  • Event-driven scaling with KEDA
  • Spot and preemptible capacity with safe fallbacks
  • Per-namespace cost allocation and showback

Deliverables

  • Cost baseline and savings opportunities report
  • Autoscaling and rightsizing changes as pull requests
  • Cost dashboards per team

Typical duration: 2–4 weeks

Get a rough figure first with the cost estimator.

GPU & AI platforms

Kubernetes platforms for model training and inference that keep expensive GPUs busy.

What’s included

  • NVIDIA GPU Operator, drivers and device plugins
  • GPU sharing with time-slicing or MIG where supported
  • Model serving with KServe
  • Pipelines with Kubeflow; distributed workloads with Ray
  • Queueing and fair-share scheduling for training jobs
  • GPU utilisation monitoring and cost tracking

Deliverables

  • GPU-ready cluster and node pools as code
  • Reference inference and training workflows
  • GPU utilisation dashboards

Typical duration: 3–8 weeks

More detail on the GPU & AI infrastructure page.

Training & enablement

Hands-on workshops on your own platform, so your team can operate confidently after we step back.

What’s included

  • Kubernetes fundamentals for developers
  • Administration workshops aligned to the CKA curriculum
  • Application development aligned to CKAD
  • Cluster security aligned to CKS
  • GitOps, observability and incident response drills
  • Pairing and shadowing during live engagements

Deliverables

  • Lab environments and exercises
  • Recorded sessions and course material
  • Skills matrix before and after

Typical duration: 2–5 days per track
