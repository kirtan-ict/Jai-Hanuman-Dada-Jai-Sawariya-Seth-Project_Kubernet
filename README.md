# Jai Hanuman Dada Jai Sawariya Seth Project – Kubernetes

Kubernetes project workspace.

## Structure

```
k8s/        Kubernetes manifests (deployments, services, config)
```

## Getting started

Prerequisites:
- [kubectl](https://kubernetes.io/docs/tasks/tools/)
- Access to a Kubernetes cluster (e.g. Docker Desktop, minikube, kind, AKS, EKS or GKE)

Apply the manifests:

```bash
kubectl apply -f k8s/
```
